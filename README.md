# AI Coding & Harness Engineering Study

> 本项目是一个**个人学习型项目**，非真实工程项目。专注于 AI 编程、Harness 工程理论、AI Coding 工具及 Agent 开发等前沿技术的系统性学习与实践记录。

---

## 📌 项目定位

这是一个用于系统学习以下方向的知识汇聚仓库：

- **AI 编程（AI Coding）**：利用 AI 辅助开发的方法论、最佳实践
- **Harness 工程理论**：测试线束、工程质量保障体系的理论与实践
- **AI Coding 工具**：主流 AI 编程工具的使用方法与横向对比
- **国内外 AI 动态**：追踪 AI 领域最新进展、研究成果与行业动态
- **主流大模型学习**：深入了解 GPT、Claude、Gemini、DeepSeek 等大模型的能力与特性
- **AI 编程工具生态**：覆盖 IDE 插件、CLI 工具、代码补全、代码生成等各类工具
- **Agent 开发**：AI Agent 架构、开发框架与实践案例

---

## 🎯 学习目标

1. 建立对 AI 辅助编程完整知识体系的认知框架
2. 掌握主流 AI Coding 工具的使用技巧与应用场景
3. 理解 Harness 工程理论在 AI 时代的实践意义
4. 跟踪国内外前沿 AI 动态，形成持续学习机制
5. 具备独立开发 AI Agent 的能力
6. 积累可复用的学习笔记、代码示例与最佳实践

---

## 📚 学习内容概览

### 一、AI 编程（AI Coding）
- AI 辅助编程的核心概念与方法论
- Prompt Engineering 在编程场景中的应用
- AI 与人类协作开发的工作流设计
- AI 编程的质量保障与 Code Review 策略

### 二、Harness 工程理论
- Harness 测试线束基本概念
- 工程测试体系的构建与管理
- AI 时代的工程质量保障新思路
- 持续集成 / 持续交付（CI/CD）与 AI 的结合

### 三、AI Coding 工具学习
- **IDE 插件类**：GitHub Copilot、Cursor、CatPaw 等
- **对话式编程类**：ChatGPT、Claude、Gemini 等
- **代码生成 / 补全工具**：Codeium、Tabnine 等
- **自动化代理工具**：Devin、SWE-agent 等

### 四、国内外 AI 动态
- 前沿论文与技术博客追踪
- 国内外主流 AI 公司动态（OpenAI、Anthropic、Google、字节、百度、阿里等）
- 大模型能力评测与排行榜解读
- AI 政策法规与行业生态观察

### 五、主流大模型学习
- **OpenAI 系列**：GPT-4o、o1、o3 等
- **Anthropic 系列**：Claude 3.x / 4.x
- **Google 系列**：Gemini 1.5 / 2.0
- **开源模型**：LLaMA、Mistral、DeepSeek、Qwen 等
- 模型能力对比：推理、代码、多模态、上下文长度等维度

### 六、AI 编程工具生态
- 工具分类与选型指南
- 各工具使用技巧与实践心得
- 工具组合使用策略（Tool Chain）

### 七、Agent 开发
- Agent 基础理论：ReAct、Plan-and-Execute、Multi-Agent 等
- 主流框架：LangChain、LlamaIndex、AutoGen、CrewAI 等
- Agent 工具调用（Function Calling / Tool Use）
- Agent 记忆管理与状态维护
- 实战案例与代码示例
